# nb

Jupyter notebooks and datasets, runnable in VS Code or Google Colab.

## Layout

```
notebooks/   one notebook per analysis; 00_template.ipynb is the starting point
data/raw/    small source datasets (committed)
data/processed/  derived outputs (git-ignored, regenerated by notebooks)
requirements.txt shared Python dependencies
```

## Run in Colab

Open any notebook via its badge, or build the URL by hand:

```
https://colab.research.google.com/github/dtenreiro/nb/blob/main/notebooks/<name>.ipynb
```

The first cell of each notebook detects Colab, clones this repo into `/content/nb`, installs `requirements.txt`, and sets `DATA_DIR` so the rest of the notebook is identical to the local version.

## Run in VS Code

```sh
git clone https://github.com/dtenreiro/nb.git
cd nb
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
nbstripout --install          # strips outputs on commit so diffs stay readable
code .
```

Install the recommended extensions when prompted (Python, Jupyter), pick the `.venv` kernel, and open a notebook.

## Adding a notebook

1. Copy `notebooks/00_template.ipynb` to `notebooks/NN_short_name.ipynb`.
2. Update the Colab badge URL in the first cell to the new filename.
3. Load data from `RAW / "file.csv"` rather than hard-coded paths.
4. Add any new dependencies to `requirements.txt`.

## Adding a dataset

- Under ~10 MB: commit to `data/raw/` and note its source in `data/README.md`.
- Larger: use Git LFS (`*.parquet` and `*.h5` are already tracked) or download it in the notebook.

## Conventions

- Notebook outputs are stripped before commit via `nbstripout`; run cells locally to see results.
- Prefix notebooks with a two-digit number to keep them ordered.
- Keep reusable code in a `.py` module next to the notebooks once it's used in more than one place.
